# Job Tracker Starter Pack

Config for building a job application tracker (React + ElysiaJS) with VS Code Copilot agents.

- `.github/copilot-instructions.md`: always-on project rules
- `.github/skills/`: design-system, api-endpoint, testing, security-review
- `.github/prompts/new-feature.prompt.md`: run with `/new-feature` in chat
- `.github/workflows/`: CI (lint, types, tests, E2E, CodeQL, secret scan, audit) and a deploy placeholder
- `.github/dependabot.yml`: weekly dependency updates
- `docs/DESIGN.md`: your visual identity (edit this first)
- `docs/FIRST-SESSION.md`: the step-by-step build guide, with prompts to paste

Start with `docs/FIRST-SESSION.md`.
